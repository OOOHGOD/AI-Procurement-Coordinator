Layer 6 - Approval (Core: Tiered Confirmation)

  • 高置信度无冲突: 自动通过，无需人工操作Auto-pass, no manual action needed
  • 中置信度/一般冲突: 轻量确认，仅核对异常项Light confirmation, verify exceptions only
  • 低置信度/致命冲突: 完整确认，逐条核对Full confirmation, verify all fields

避免"全量人工确认"，聚焦异常项，提升效率

Avoids full manual verification, focuses on exceptions

AI Agent 技术方案工作流

AI Agent Workflow Blueprint

在现有 8 层主链路之上增加可编排的 Agent 层：负责多轮澄清、结构化订单生成、冲突判断、人工确认路由和工具调用，把“AI 解析”升级为“可控执行”。

Add an orchestrated agent layer on top of the existing 8-layer pipeline: clarify requirements, generate structured orders, detect conflicts, route human approval, and call tools with controlled execution.
