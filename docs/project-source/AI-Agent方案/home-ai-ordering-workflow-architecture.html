Agent 角色与工具边界

Agent Roles & Tool Boundaries

把“谁来判断、谁来调用工具、调用后写到哪里”拆清楚。Agent 只做可审计动作，核心订单状态仍由后端和数据库承载。

Clarify who decides, who calls tools, and where results are written. Agents execute auditable actions while the backend owns order state.

01核心订单状态放在后端和数据库，不放在 n8n。Core order state lives in the backend and database, not in n8n.
02低置信度、冲突、缺失字段必须中断到人工确认。Low confidence, conflicts, and missing fields interrupt to human review.
03工具调用只执行可审计动作，每次调用都写入追踪记录。Tool calls execute auditable actions and write trace records every time.
