WORKFLOW — 7 层主链路
1
数据入口
邮件 / WhatsApp / 文件上传 / 表单 / 云盘
IMAP / SMTP WhatsApp Business API REST upload
2
原始资料库
保存原文件、来源、发送人、时间、项目

3
AI 解析层
OCR / 表格识别 / PDF 解析 / 大模型 JSON 抽取
OCR → PaddleOCR LLM structured extract 多模态理解
4
订单数据库
项目、房间、商品、规格、数量、供应商、版本、状态
Supabase / PG item_versions 可追溯 JSONB
5
规则与 Agent 层
最新版本判断 · 冲突检测 · 缺失字段检测 · 供应商匹配
业务规则引擎 AI Version Agent Risk Scorer
6
确认与审批层
低风险自动通过，高风险人工逐条确认后进入发单
Human-in-the-loop Approval Queue Version evidence
7
输出执行层
PDF / Excel / 邮件或 WhatsApp 发给工厂 & 状态追踪
PDF template engine SMTP / WA Business Status webhook
