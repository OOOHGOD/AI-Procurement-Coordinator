AI Order Agent Feasibility Report

结论优先

家装下单 Agent 可以做，但不建议第一天就完全无人下单。

最务实的路线是：先让系统自动整理资料、判断最新需求、生成工厂文件；正式发给工厂前保留确认。等准确率和供应商规则稳定后，再逐步开放自动下单。

可行

技术上能做，商业上有价值。最大风险不是生成文件，而是错误下单带来的生产损失。

一、项目整体技术路线

把所有散乱信息先集中，再变成标准订单数据，最后输出给工厂。系统要记录每条数据从哪里来，方便追责和复查。

推荐路线
1

统一收资料

邮件、WhatsApp、微信截图、PDF、图片、Excel、云盘文件进入同一个入口。

2

自动读内容

系统读取图片和 PDF，把文字、表格、尺寸、数量、颜色、材质提取出来。

3

整理成订单

按项目、房间、品类、供应商整理，生成统一的商品清单。

4

判断最新版本

如果客户反复修改，系统优先保留最新要求，同时保存历史记录。

5

检查风险

缺尺寸、数量冲突、图片和文字不一致时，系统自动标出异常。

6

输出和下单

生成工厂 PDF、采购单、邮件或 WhatsApp 消息。高风险订单先确认再发送。

建议不要把 n8n 当成整个系统本身。n8n 适合做早期流程连接，例如收邮件、调 AI、发通知；核心订单数据、版本记录和权限控制应放在独立数据库和后台系统里。

二、技术可行性详细分析

系统大部分环节可实现。最需要谨慎的是微信接入、版本判断、以及自动发给工厂这一步。

能做，但要分级放权
模块可行性落地方式主要风险建议策略

WhatsApp 接入较高使用 WhatsApp Business API 或 n8n 节点需要企业账号和合规配置适合作为首批自动入口

三、行业主流同行技术路径对比

同行通常不会从“全自动发单”开始，而是先解决规格、采购单、供应商、交期、文件版本这些基础问题。

重点管理规格表、产品图片、采购单、供应商、交付状态。适合酒店、家装、FF&E 项目。

AI 文档处理平台

重点把 PDF、图片、报价单、订单文件变成标准表格，再做校验和系统对接。

自动化流程平台

n8n 这类工具适合连接邮件、云盘、AI、数据库和消息通知，适合快速做 MVP。

路径代表做法优点不足对本项目的启发
传统采购管理软件规格表、PO、供应商、交期管理稳定，适合项目管理对混乱聊天和图片的自动理解较弱我们需要学习它们的订单结构和状态管理
AI 文档抽取平台从 PDF、图片、Excel 中抽取字段处理资料快，能减少人工录入不一定懂家装业务流程适合作为本项目的核心能力之一
n8n / Zapier 类流程工具把邮件、文件、AI、数据库、通知串起来启动快，成本低，方便试错复杂业务和长期数据管理能力有限适合首版，后期应逐步自研核心后台
完全自研系统自建后台、数据库、权限、供应商门户长期可控，适合规模化周期更长，初期成本更高适合在 MVP 验证成功后推进

四、建议分阶段实施

先验证能不能把混乱信息整理准确，再考虑自动下单。这样投资风险最低。

成本可控

  • 标出缺失和冲突

第 2 阶段：标准输出

  • 生成工厂 PDF

六、老板最关心的答案

下面是适合直接汇报的版本。

决策摘要

能不能做？

能做。首版应先做“自动整理 + 自动生成 + 人工确认”，不要直接承诺全自动下单。

怎么做最稳？

用 n8n 快速连接流程，用数据库保存订单和版本，用 AI 读取资料，用后台页面审核。

最大风险是什么？

不是技术做不出来，而是客户信息混乱导致错误下单，所以必须有冲突检测和追溯记录。

首版做多大？

4-8 周做出可演示闭环：上传资料、AI 整理、人工确认、生成工厂 PDF。

参考方向：Techstyles FF&E Procurement、FF&EZ Design Purchasing、TableFlow document extraction、n8n Human in the Loop、n8n WhatsApp node。

Executive conclusion

The home furnishing order agent is feasible, but full no-human ordering should not be the first release.

The practical route is to automate data collection, latest requirement detection, and factory-ready document generation first. Final order sending should stay controlled until accuracy and supplier rules are proven.

Feasible

The technology is available and the business value is clear. The main risk is not making a PDF; it is sending the wrong order to production.

1. Overall Technical Route

Collect scattered information into one place, turn it into standard order data, then generate supplier-ready documents. Every key value should keep its source for review.

Recommended route
1

Collect inputs

Email, WhatsApp, WeChat screenshots, PDFs, images, spreadsheets, and cloud files enter one inbox.

2

Read content

The system reads text, tables, sizes, quantities, colors, and materials from files.

3

Build orders

Data is grouped by project, room, category, and supplier into a clean item list.

4

Find latest version

When clients make changes, the system keeps the newest requirement and stores old versions.

5

Check risks

Missing sizes, conflicting quantities, and image-text mismatches are flagged before ordering.

6

Output and order

Generate factory PDFs, purchase orders, emails, or WhatsApp messages. High-risk orders require confirmation.

n8n is best used as an early workflow connector, not as the whole system. Core order data, versions, and permissions should live in a proper database and business backend.

4. Recommended Phased Delivery

Validate accurate data organization before automatic order sending. This keeps investment risk low.

Cost controlled

Phase 1: Data MVP

  • Upload PDFs, images, spreadsheets, chat records
  • Generate item list
  • Flag missing and conflicting data

Phase 2: Standard outputs

  • Generate factory PDF
  • Generate purchase order
  • Split by supplier

Phase 3: Semi-automatic ordering

  • Prepare low-risk orders automatically
  • Confirm high-risk orders
  • Record sent messages and replies

Phase 4: Gradual autonomy

  • Auto-send to approved suppliers
  • Track status automatically
  • Connect finance and ERP systems

6. Decision Summary

A concise version for executive discussion.

Board-level summary

Can we build it?

Yes. The first release should automate organization and document generation, with controlled approval before ordering.

What is the safest route?

Use n8n for fast workflow connection, a database for order history, AI for reading documents, and a simple review portal.

What is the biggest risk?

The risk is not technology failure; it is wrong orders caused by unclear client information.

How big should the MVP be?

4-8 weeks: upload files, AI organizes data, user confirms, and the system generates factory PDFs.
