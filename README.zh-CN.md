# AI 采购协调助手

面向家装、酒店和工程采购的信息整理与工作流设计研究。当前仓库包含需求拆解和 HTML 可行性报告，尚未提供可运行的 Agent、后端或生产集成。

## 阅读入口

- [可行性报告](feasibility-report.html)：下载后用浏览器打开。
- [任务拆解](家装下单工作流任务拆解文字稿.md)：角色、流程、字段、人工确认与实施阶段。

拟议流程包括多源资料归集、字段抽取、版本和冲突识别、分类以及生成供人工确认的订单文件。以上是设计目标，不代表已经实现。阅读材料无需安装依赖或 API 密钥。
